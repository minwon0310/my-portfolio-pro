컴퓨터를 꺼도 24시간 핸드폰 접속 설정 (무료 클라우드 배포)

아래 두 가지 방법 중 하나로 올리면 PC가 꺼져 있어도 24시간 LTE/5G에서 작동합니다

방법 1. GitHub Pages + 매일 오전 8시 클라우드 자동 업데이트 (추천)

1) GitHub에서 새 저장소(Repository)를 만들고 이 폴더(portfolio-tracker)의 파일들을 업로드합니다.
2) 저장소의 Settings → Pages → Branch: main 저장 시 24시간 접속 링크가 생성됩니다.
3) 내장된 .github/workflows/daily_update.yml이 컴퓨터가 꺼져 있어도 매일 아침 8시(한국시간) 클라우드에서 주가·배당을 자동 갱신합니다!

방법 2. 10초 만에 드래그&드롭 배포 (Netlify Drop)

회원가입이나 복잡한 설정 없이 app.netlify.com/drop 에 접속해 portfolio-tracker 폴더를 마우스로 끌어다 놓으면 즉시 평생 무료 HTTPS 모바일 주소가 발급됩니다.

24시간 모바일/클라우드 접속 주소 (클릭하여 복사):

• 아이폰(Safari): 접속 후 하단 공유[↑] → '홈 화면에 추가'
• 갤럭시(Chrome): 접속 후 우측 상단 메뉴[⋮] → '홈 화면에 추가 / 앱 설치'
